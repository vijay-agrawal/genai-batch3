# Assignment 1 — The Power of the System Prompt: MedScribe Discharge Summary Assistant

## Background

CitiusTech is building **MedScribe**, a conversational AI assistant for hospitalists
and resident physicians at a 500-bed US hospital. The assistant collects structured
information from the physician through a natural dialogue and generates a
**CMS-compliant Discharge Summary** that can be directly imported into Epic via HL7 FHIR.

This assignment teaches you that the **system prompt is the architecture** — every
clinical behaviour, constraint, and output format the model produces in production
flows from it.

This assignment tests your ability to:

- Design a **multi-turn system prompt** that drives a structured clinical workflow
- Use the LLM itself as a **field validator** (ICD-10 code plausibility, drug name check)
- Combine **output format control** (FHIR-ready discharge note) with **role prompting**
- Handle **graceful re-prompting** for invalid or incomplete clinical input

---

## What MedScribe Must Do

```
Step 1 — Greet the physician by name (extracted from the first message)
Step 2 — Collect the following fields ONE AT A TIME (do not ask multiple questions
          in a single turn):

  Patient Demographics
  ────────────────────
  • Patient MRN           (format: MRN-XXXXXXXX, 8 alphanumeric chars)
  • Patient Full Name
  • Date of Birth         (MM/DD/YYYY — patient must be between 0 and 120 years)
  • Gender                (Male / Female / Non-binary / Unknown)
  • Primary Insurance     (Medicare / Medicaid / Commercial / Self-Pay)

  Admission & Discharge
  ─────────────────────
  • Admission Date        (MM/DD/YYYY)
  • Discharge Date        (MM/DD/YYYY — must be ≥ admission date)
  • Discharge Disposition (Home / SNF / Rehab / AMA / Expired / Transfer)
  • Attending Physician   (full name)
  • Hospital Unit         (e.g. 4N Medical Telemetry, MICU, 7S Oncology)

  Clinical Summary
  ────────────────
  • Primary Diagnosis     (free text — must map to a plausible ICD-10 category)
  • Secondary Diagnoses   (up to 4, comma-separated — or "None")
  • Principal Procedure   (free text — or "None")
  • Discharge Medications (free text list — validate each drug name is plausible)
  • Follow-up Required    (Yes / No — if Yes, collect specialist and timeframe)
  • Pending Results       (free text — or "None")

Step 3 — Confirm all collected details before generating the note
Step 4 — Generate the structured discharge summary in the exact format below
```

## Validation Rules (LLM-Driven)

| Field | Validation Rule |
|---|---|
| MRN | Format `MRN-` followed by exactly 8 alphanumeric characters |
| Date of Birth | Patient must be between 0 and 120 years old |
| Discharge Date | Must be on or after Admission Date; no future dates |
| Primary Diagnosis | Must map to a recognisable ICD-10 category (e.g. "chest pain" → I20–I25; reject gibberish) |
| Discharge Medications | Each drug name must be a plausible pharmaceutical. Reject invented names like "Healitol 500mg" |
| Discharge Disposition | Must be one of the 6 allowed values; reject free text like "went home" |
| Follow-up Timeframe | If Follow-up = Yes, must specify specialist type and timeframe (e.g. "Cardiology in 2 weeks") |

# Assignment 5 — Bias and Hallucination in Healthcare AI

## Background

CitiusTech's AI Governance team must audit clinical AI outputs for two failure modes
before any model reaches production:

1. **Hallucination** — fabricated drug names, dosages, clinical trial references, or
   lab values that a clinician might act on
2. **Demographic bias** — systematically different clinical recommendations based on
   patient age, gender, race, or socioeconomic status

Both failure modes appear in published literature on clinical LLMs and carry
regulatory implications under FDA AI/ML-based SaMD guidance and ONC HTI-1 rules.

---

## Part A — Triggering Clinical Hallucination

### Why Healthcare LLMs Hallucinate

LLMs hallucinate in healthcare contexts because:
- Rare diseases have thin training data; the model fills gaps with plausible-sounding specifics
- Clinical trial citation structure is predictable, making fake citations easy to generate
- Drug naming conventions follow patterns the model can imitate
